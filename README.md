## 价格表里三个最容易踩的坑

先说结论：首年价、带宽数字、产品类型，这三处是「云主机价格一览表」里最容易看走眼的地方，每一个都能让你多花几百块。

**坑一：首年便宜，第二年翻倍。**

阿里云那个 99 元的 2核2G 之所以值得写进表里，是因为它标了「续费同价，可续 2 次」——三年一共 297 元。同样标价 99 元的机器如果没有这条，第二年按原价续，三年下来差距能到几百元。看价格表时，把续费价那一列补上，算出来的才是真实成本。

**坑二：带宽数字不能直接比大小。**

「200M 峰值带宽」和「3M 固定带宽」不是一个东西。峰值是短时间能冲到的上限，持续跑满会被限速，通常还捆着月流量包；固定带宽是你随时都能用的那部分。所以 2核2G + 200M 卖 68 元，和 2核2G + 3M 卖 99 元，不能简单说前者更划算——前者适合图文站、下载类突发流量，后者适合接口服务这种持续有请求的场景。

**坑三：虚拟主机混进了「云主机」价格表。**

阿里云共享型虚拟主机经济增强版 119 元/年，价格看着和入门云服务器差不多，但它没有独立 CPU 资源，配置是 2GB 网页空间、500MB 数据库、每月 40GB 流量。同价位能买到 2核2G、3M 带宽的轻量应用服务器，108 元/年，配置高一截。标题写着「云主机」的表格里混进虚拟主机，是最常见的一种误导。

## 同价位横向比较：阿里云和腾讯云怎么挑

配置接近时，先比续费条款，再比带宽口径，最后才比首年价。按这个顺序，两台机器的差别通常一目了然。

| 对比项 | 腾讯云 续费同价专区 | 阿里云 99计划 e 实例 |
| --- | --- | --- |
| 配置 | 2核4G | 2核2G |
| 首购价 | 188 元/年 | 99 元/年 |
| 续费 | 同价 | 同价，可续 2 次 |
| 三年花费 | 若一直同价续费，约 564 元 | 297 元 |

这两台机器差 89 元/年，换来的是内存翻倍。跑数据库、跑 Docker、跑带后台的 CMS，2G 内存很容易在装完环境后就不够用；只放静态页面或做课程作业，2G 完全够，多花的钱用不上。

阿里云同价位还有 2核4G 的 u1 机型，活动价 199 元/年。和腾讯云那台 188 元的配置对齐后只差 11 元，这时候该比的就不是价格了，而是系统盘大小、带宽类型和续费规则。

个人博客、作品集、课程作业，2核2G 就够。访客主要在国内，选国内机型的续费同价档，访问快；想省掉备案流程，腾讯云境外 2核2G 99 元/年更直接。

小型游戏服（我的世界、饥荒、幻兽帕鲁这类），腾讯云按人数打包的套餐最省事，4 人档约 8G、8 人档约 16G。先买 3 个月，活跃度稳定了再续。

外贸站和独立站，2核4G 比 2核2G 稳。WordPress 装几个插件、开个缓存，2G 内存就吃紧了，199 元/年那档更抗造。

长期跑的业务系统，只挑标了「续费同价」的机型。省下来的续费差价，一年就够再买一台。

## 下单前要确认的四件事

1. **新用户身份只有一次。** 云厂商按实名认证计算，一个实名下只有一次首购资格。为了试水买一个月，可能把后面三年的优惠价一起用掉。
2. **把续费价写进预算表。** 活动页价格旁边通常有小字说明，找不到就直接问客服要续费报价，别靠猜。
3. **带宽和流量包分开看。** 固定带宽、峰值带宽、月流量包是三个概念，任意一个用错都会影响实际体验。
4. **地域决定要不要备案。** 境外机房不用备案，国内访问会慢一些；国内机房要备案，走完流程需要时间。

预算卡在 100 元以内、只做站和测试，选境外 2核2G 99 元/年；不想第二年再折腾一遍，选续费同价专区 2核4G 188 元/年；开游戏服就直接按人数选打包套餐，先买 3 个月。
